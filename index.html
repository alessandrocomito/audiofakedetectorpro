Overview

Audio Fake Detector PRO is an audio analysis tool designed to detect lossy-to-lossless transcodes and artificially upscaled audio files that are commonly mislabeled as high-quality sources.

The engine combines spectral analysis, statistical validation, and multi-segment voting logic to reduce false negatives in mixed or partially clean audio material.

Detection Engine

Each audio file is divided into multiple non-final segments. The final segment is treated as a secondary indicator only and excluded from voting.

Half-or-Strict-Majority Wall Vote: A file is flagged as FAKE if: - ≥ 50% of segments (even N) OR - strict majority (odd N) show spectral wall ≤ 16.5 kHz Tie condition → default FAKE

Grey zone (16.5–18.5 kHz) is excluded from voting logic to reduce false positives on high-bitrate encodes. In this case, classification becomes SUSPECT rather than FAKE.

Analysis Methods

  • Spectral cutoff detection
  • High-frequency drop near track end
  • Joint stereo anomaly detection
  • Multi-segment frequency consistency analysis
  • auCDtect statistical validation (lossless only)
  • 3-step metadata fallback recovery

Processing Pipeline

  • 1. Format detection & decoding (ffmpeg / ffprobe)
  • 2. Segmentation of audio stream
  • 3. Spectral analysis per segment
  • 4. Voting system aggregation
  • 5. Final classification (CLEAN / SUSPECT / FAKE)

Output

  • Suspicious files moved to ~Fake folder
  • Reports exported in LOG / CSV / HTML formats
  • Original folder structure preserved

Technical Notes

  • Requires Windows 10/11 (32/64-bit)
  • PowerShell 5+
  • First-run dependency download required
  • Portable mode supported (zero system changes)
  • Resume scan after interruption supported

Limitations

  • Speech or voice-only content.
  • Very old, degraded, or acoustic recordings with limited bandwidth.
  • Close-quality transcodes (e.g., MP3 192 kbps -> AAC 224 kbps).
  • High-bitrate AAC (320 kbps) -> FLAC, as modern AAC encodes preserve near full-band spectral content without stable artifacts.
