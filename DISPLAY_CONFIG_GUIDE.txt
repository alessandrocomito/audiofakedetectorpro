DISPLAY CONFIGURATION GUIDE
===========================

This guide explains how to correctly configure the console window
 for optimal readability and proper text output.

This is a one-time setup per executable.

-----------------------------------------------
1. OPEN APPLICATION
-----------------------------------------------
Double click the executable (.exe)

-----------------------------------------------
2. OPEN CONSOLE PROPERTIES
-----------------------------------------------
Right-click on the window title bar
Select: Properties

-----------------------------------------------
3. CHARACTER
-----------------------------------------------
Select TAB: CHARACTER

Font
Font name : Lucida Console / Consolas
Size      : 16 		       / 20

-----------------------------------------------
4. LAYOUT
-----------------------------------------------
Select TAB: LAYOUT

WINDOW SIZE
Width  : 118
Height : 40		            / 32

BUFFER SIZE
Width  : 118
Height : 3000

Click OK to confirm

-----------------------------------------------
IMPORTANT NOTES
-----------------------------------------------
Only modify the settings shown above.
Do not change other options.

Settings are stored per executable in Windows.

-----------------------------------------------
EXPECTED RESULT
-----------------------------------------------
Clear text output
No line wrapping issues
Full log visibility
Scrollback enabled

-----------------------------------------------
QUICK SUMMARY
-----------------------------------------------
Font         : Lucida Console 16 / Consolas 20
Buffer Size  : 118 x 3000
Window Size  : 118 x 40         / 32

-----------------------------------------------
END OF GUIDE
-----------------------------------------------
