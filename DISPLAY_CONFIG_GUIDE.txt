DISPLAY CONFIGURATION GUIDE
===========================

This guide explains how to correctly configure the console window
for optimal readability and proper text output.

This is a one-time setup per executable or script.

----------------------------------------------------
1. OPEN APPLICATION
----------------------------------------------------
Double click the executable (.exe) or

Double click Start_script.cmd and select, if 2
scripts are in current folder:
1 - Portable version or
2 - Standard version

----------------------------------------------------
2. OPEN CONSOLE PROPERTIES
----------------------------------------------------
Minimize the selection window

Right-click on the window title bar of the exe or
Windows PowerShell

Select: Properties

----------------------------------------------------
3. FONT
----------------------------------------------------
Select TAB: Font

Font name : Consolas       / Lucida Console
Size      : 20             / 16

----------------------------------------------------
4. LAYOUT
----------------------------------------------------
Select TAB: Layout

WINDOW SIZE
Width    : 118             / 118
Height   : 32              / 40

Click OK to confirm

----------------------------------------------------
IMPORTANT NOTES
----------------------------------------------------
Only modify the settings shown above.
Do not change other options.

Settings are stored per executable in Windows.

----------------------------------------------------
EXPECTED RESULT
----------------------------------------------------
Clear text output
No line wrapping issues
Full log visibility
Scrollback enabled

----------------------------------------------------
QUICK SUMMARY
----------------------------------------------------
Font         : Consolas 20       / Lucida Console 16
Window Size  : 118 x 32          / 118 x 40

----------------------------------------------------
END OF GUIDE
----------------------------------------------------
